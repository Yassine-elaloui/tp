# TaskFlow - Gestion des tâches

Application de gestion des tâches créée avec React, Vite et Recharts.

## Fonctionnalités
- Ajouter, modifier et supprimer une tâche.
- Définir une date de début et une date de fin.
- Choisir le statut : À faire, En cours ou Terminée.
- Afficher les statistiques et un diagramme circulaire.
- Filtrer les tâches par statut.
- Sauvegarder les tâches dans le navigateur avec localStorage.

## Installation

```bash
npm install
npm run dev
```

Ouvrir ensuite l'adresse affichée dans le terminal (généralement http://localhost:5173).

## Générer la version de production

```bash
npm run build
```
